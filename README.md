# Automatic Attendance System using Face Recognition with 2FA

## Project Description
This is a Final Year BE AIML project that implements an Automatic Attendance System using Face Recognition combined with Two-Factor Authentication (2FA) for enhanced security.

## Features
- Face recognition-based attendance
- Voice / OTP-based secondary authentication
- Secure attendance logging
- Database storage

## Technologies Used
- Python
- OpenCV
- CNN
- Flask
- HTML, CSS, JavaScript
